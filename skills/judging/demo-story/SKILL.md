# Demo story

Cel: w 110 s pokazac, ze produkt **podejmuje decyzje**, a nie tylko rysuje ramki.

## Luk
| Czas | Tresc |
|---|---|
| 0-15 s | problem: prog ustawiony recznie klamie na innej scenie |
| 15-45 s | inspekcja + werdykt (ramki, liczby) |
| 45-80 s | scena trudna -> agent zmienia prog -> druga inspekcja |
| 80-100 s | przypadek bez dowodu -> `request_rescan` (silnik mowi "nie wiem") |
| 100-110 s | wynik benchmarku (delta 0.0000) i link |

## Zasada
Kazdy kadr ma jedna teze. Brak muzyki budujacej napiecie bez pokrycia w obrazie.
Zero animowanych napisow udajacych UI — pokazujemy realny ekran.
